# Specs

Spec Kit project for the Authdog CLI. Constitution and templates live in
[`.specify/`](../.specify/). Command behavior remains in [`SPEC.md`](../SPEC.md).

Do not add new feature plans as flat files at this root. A folder name
must state a purpose (`NNN-purpose`), and the feature branch must use
the same name.
